# Publicador Videos Virales

Herramienta personal para crear y publicar videos cortos en la propia cuenta de TikTok del creador. Usa el inicio de sesión de TikTok (Login Kit) y la API de publicación de contenido (Content Posting API) solo con la autorización del usuario.

Es de uso privado: no ofrece cuentas a terceros ni vende datos.

- Política de Privacidad: https://gyggarzon1-sys.github.io/publicador-videos-virales/privacidad.html
